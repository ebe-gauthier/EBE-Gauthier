This repository contains the implementation of three advanced Java projects as part of the Software Engineering course. Each project follows object-oriented principles, encapsulation, validation, and reporting features.

---

## 📝 Assignment Overview

###  Exercise 1: Advanced Stock Management System
- Manages stock across product categories like Electronics, Clothing, Groceries, etc.
- Features:
  - Abstract and concrete product classes
  - Supplier, Product, and Warehouse encapsulation
  - Report generation and validations

###  Exercise 2: Advanced Online Shopping System
- Simulates a full e-commerce experience from product listing to payment.
- Features:
  - Abstract `ShoppingItem` with 5 specialized types
  - Encapsulated `Customer`, `ShoppingCart`, and `Payment` classes
  - Discounts, stock handling, and invoice generation

###  Exercise 3: Advanced Motor Vehicle Insurance System
- Handles vehicle insurance policies, claims, and premium calculations.
- Features:
  - Abstract `InsurancePolicy` with 5 policy types
  - Encapsulated `Vehicle`, `Person`, and `Claim` classes
  - Claim validation, policy reporting, and premium computation
